📲 How to install on Android

  1. Tap "Download ZIP".
  2. Open a file manager (e.g., ZArchiver).
  3. Extract the ZIP to a folder.
  4. Open Kiwi Browser → kiwi://extensions.
  5. Enable Developer mode → "Load unpacked".
  6. Select the folder → Done!

⚠️ For iOS: This extension does not work on iOS.
